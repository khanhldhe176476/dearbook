## 📊 DESIGN WORKFLOW DIAGRAM

```
DESIGN PROCESS:
┌─────────────┐
│ 1. SKETCH   │
│   BASE      │ → Draw face, neck, shoulders (no hair/outfit)
└──────┬──────┘
       │
       ↓
┌─────────────┐
│ 2. CREATE   │
│   HAIR      │ → Draw 6 hairstyles on separate files
│   LAYERS    │   (same canvas size, align with base)
└──────┬──────┘
       │
       ↓
┌─────────────┐
│ 3. CREATE   │
│   OUTFIT    │ → Draw 6 outfits on separate files
│   LAYERS    │   (same canvas size, align with base)
└──────┬──────┘
       │
       ↓
┌─────────────┐
│ 4. TEST     │
│   COMPOSITE │ → Stack layers, check alignment
└──────┬──────┘
       │
       ↓
┌─────────────┐
│ 5. EXPORT   │
│   PNG       │ → Export each layer as transparent PNG
└──────┬──────┘
       │
       ↓
┌─────────────┐
│ 6. OPTIMIZE │
│   & DELIVER │ → Compress, organize folders
└─────────────┘
```
